# Вандроўка — Expo Go

Обязательный способ разработки — Expo Go на физическом Android-телефоне.
Эмулятор не запускаем. Сейчас доступны стартовый экран, подсказки, три вкладки, список мест Минска
и карточка из backend, карта Mapbox через WebView. Игровой API ещё не подключён.

## Запуск

Нужны Node.js 22.23.2, npm и Expo Go, совместимый с SDK 57.
Если установленный Expo Go сообщает о несовместимом SDK, установите Android-версию
для SDK 57 с официальной страницы https://expo.dev/go.
Java/Android SDK и собственный APK для этого способа запуска не нужны.

```bash
cd mobile
nvm use
npm ci
npm start
```

Телефон и компьютер должны быть в одной локальной сети. Откройте проект
по QR-коду в Expo Go. Скрипт явно задаёт `--go`, даже при установленном
expo-dev-client (он сохранён для необязательных собственных сборок).

## По USB

Нужны adb, отладка по USB и разрешение подключения на телефоне.
`adb devices` должен показывать физический телефон в состоянии `device`.
Замените PHONE_SERIAL его серийным номером:

```bash
adb -s PHONE_SERIAL reverse tcp:8081 tcp:8081
npm run start:usb
```

В Expo Go введите `exp://127.0.0.1:8081`. Можно открыть ссылку через adb:

```bash
adb -s PHONE_SERIAL shell am start -a android.intent.action.VIEW -d exp://127.0.0.1:8081
```

Эти команды не запускают эмулятор и не устанавливают собственный APK.

## Конфигурация и ограничения

Адрес backend хранится в `mobile/.env.local` (не в корневом env).
Для USB локальный файл уже подготовлен:

```dotenv
EXPO_PUBLIC_API_URL=http://127.0.0.1:8080
```

Запустите backend отдельно (см. корневой README), затем:

```bash
adb -s PHONE_SERIAL reverse tcp:8080 tcp:8080
adb -s PHONE_SERIAL reverse tcp:8081 tcp:8081
npm run start:usb
```

8080 — HTTP API, 8081 — Metro. Reverse необходимо повторять после переподключения
телефона/перезапуска adb. Для независимой проверки откройте в браузере телефона
`http://127.0.0.1:8080/health`: ожидается HTTP 200 и `{"status":"ok"}`.
Это проверяет телефон → backend. В API-клиенте также доступен метод `api.health()`.

Для Wi-Fi замените значение на адрес компьютера, например
`EXPO_PUBLIC_API_URL=http://192.168.1.100:8080`. Телефон должен быть в той же сети;
проверьте доступ к порту 8080 и отсутствие изоляции клиентов в Wi-Fi.
В браузере телефона откройте `http://192.168.1.100:8080/health`.
Адреса `0.0.0.0`, `postgres`, `api` не являются адресом компьютера для телефона.

После изменения env полностью перезагрузите проект в Expo Go (Reload).
`src/config/api.ts` читает переменную через поддерживаемое Expo обращение
`process.env.EXPO_PUBLIC_API_URL`. При отсутствии переменной используется USB-адрес;
пустое или некорректное значение вызывает ApiConfigurationError.
Поддерживается только корневой HTTP(S)-адрес без пути, credentials, query и fragment;
завершающий `/` удаляется. API-клиент использует
`getApiBaseUrl()`. Раздел «Исследовать» загружает места и категории Минска;
карточка запрашивается по числовому ID.
Серверные токены Mapbox и пароли нельзя помещать в EXPO_PUBLIC-переменные.

Карта по решению пользователя — Mapbox GL JS через react-native-webview.
WebView входит в Expo Go SDK 57; интеграция реализована, фактическая работа
Mapbox/WebGL на телефоне ещё требует проверки. Серверные Mapbox Matrix/Directions сохраняются.
Нативный Mapbox SDK не используем.
Новые библиотеки должны поддерживать Expo Go используемой версии SDK.

`android/` и `ios/` генерируются Expo и игнорируются Git. Ранее собранный
ARM64 development APK относится к другому способу запуска; для Expo Go он не нужен.
Профили EAS сохранены для будущей автономной preview/release-сборки.

## Навигация

«Начать прогулку» открывает вкладки «Исследовать», «Посещения», «Профиль».
В исследовании загружается серверный список мест Минска. Выбор места
открывает его карточку поверх вкладок.
Профиль и посещения показывают пустые состояния без вымышленного прогресса.
Маршруты находятся в `src/app/`, компоненты экранов — в `src/components/`.
Подробности и сценарии ручной проверки: [отчёт 17 октября](../docs/day-17-mobile-navigation.md).

## Общие компоненты

`src/components/ui/`: AppButton (disabled/loading), LoadingState, ErrorState
(повтор и необязательный Request ID), EmptyState, PlaceCard и общие цвета.
Список и карточка используют загрузку, ошибку с повтором и пустые состояния.

## API-клиент

`src/api/client.ts`: health, города, категории города, список мест с category/q,
карточка по числовому ID. Проверяются необходимые мобильному клиенту поля JSON;
остальные поля ответа пока не используются. HTTP APIError сохраняет status,
code и X-Request-ID. Сетевые ошибки не раскрывают текст внутренних исключений.
Таймаут 10 секунд включает чтение тела ответа. Автоматических повторов нет.
Ошибочная конфигурация адреса показывается как ошибка загрузки.

`useApiResource` отменяет запрос при уходе с экрана, смене ID и размонтировании,
не применяет запоздалые результаты. При возврате на экран данные загружаются
заново. Отмена не показывается как ошибка. «Повторить» выполняет новый запрос.
Backend должен работать отдельно; при выключенном сервере ожидаема ошибка связи.
Профиль и посещения серверные данные пока не используют; карта берёт места из каталога.

`npm test` проверяет контракт и отказы на фиктивном fetch без сети/Mapbox/БД.
19 октября пользователь подтвердил сквозную проверку в Expo Go на CMF Phone 2
по Wi-Fi: список, карточка, навигация и восстановление после остановки API.

## Карта Mapbox (этап 18 октября)

В «Исследовать» теперь есть режимы «Карта / Список». Карта использует Mapbox GL JS
3.33.0, пользовательский стиль Mapbox Standard, центр Минска и маркеры из того же backend-каталога.
Нажатие на маркер открывает обычную карточку по числовому ID. Список остаётся
доступным при ошибке WebGL, сети, отсутствующем или неверном токене.

Добавьте в `mobile/.env.local` отдельный **публичный** токен Mapbox:

```dotenv
EXPO_PUBLIC_MAPBOX_ACCESS_TOKEN=pk.ВАШ_ПУБЛИЧНЫЙ_ТОКЕН
```

Это значение включается в приложение. **Секретный `sk.*` из backend не копировать.**
Используйте публичный токен с разрешениями для чтения стилей/шрифтов карты;
ограничения URL должны допускать выбранный WebView-origin. У inline HTML может
быть origin null/about:blank — web-токен с привязкой к домену сайта может дать 403.
Не ослабляйте существующий серверный токен: для мобильной карты нужен отдельный.
После изменения env сделайте полный Reload в Expo Go.

При открытии карты идут реальные запросы Mapbox (JS/CSS, стиль, тайлы, шрифты),
которые могут расходовать квоту. Без валидного pk-токена WebView не создаётся.
Нет автоматического цикла перезагрузки: повтор только по кнопке пользователя.
При переключении карта/список и возврате из карточки WebView сохраняется,
обновляются только маркеры; полный Reload приложения и ручной повтор создают карту заново.
Кэш тайлов не является обещанием работы офлайн. GPS и построение маршрутов
на этом этапе не подключены. Логотип/атрибуция Mapbox сохранены.

Проверка на телефоне: Минск и маркеры → выбор места → назад → список/карта;
проверить жесты, масштабирование и атрибуцию. Затем отдельно проверить отсутствие
токена, неверный токен, недоступность интернета и backend. На пустом каталоге
показывается пустое состояние. Ни один сценарий не требует эмулятора.

Текущий стиль: `mapbox://styles/mpaprotski911/cmvfoqaqv00fl01s60qij53my`.
URL хранится в `MAP_STYLE_URL` (`src/map/document.ts`). Опубликованный стиль
проверен публичным токеном: HTTP 200. Изменения в Studio нужно публиковать;
для проверки обновлённого оформления выполните Reload в Expo Go.

Inline WebView использует виртуальный baseUrl `https://app.vandrouka.local/`
для стабильного HTTPS-origin. Сеть к этому адресу не запрашивается. Если у
публичного Mapbox-токена настроены allowed URLs, учитывайте данный origin.

## Карточка и геолокация (19 октября)

Карточка показывает время осмотра, билеты, расписание с перерывами/исключениями,
местный часовой пояс и ссылки-источники. Изображений в API пока нет — показана
заглушка. «Как добраться» открывает внешние карты, ошибки обрабатываются.

«Моё местоположение» определяет одну свежую позицию только по нажатию.
Синий маркер — положение на момент запроса, не фоновое слежение. Подписка GPS
удаляется после результата/таймаута/отмены; при уходе или фоне точка очищается.
Повторное получение — вручную. Для постоянного запрета доступен переход к настройкам.
В Expo Go системный диалог относится к разрешениям самого Expo Go.
Сценарии проверки: [отчёт этапа](../docs/day-19-place-location.md).
