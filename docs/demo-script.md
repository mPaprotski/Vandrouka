# Демонстрация Вандроўкі

Цель показа — пройти путь от выбора культурного места до личной истории
открытий. Ориентировочная продолжительность 5–7 минут.

## Подготовка

Записать версию и SHA256 APK, ревизию backend и адрес API в отчёте приёмки.
Зарядить телефон, проверить интернет и разрешения камеры/GPS.
На публичном backend открыть `/health` и дождаться успешного ответа.
Использовать отдельный тестовый аккаунт.

Для показа в помещении заранее подтвердить реальные посещения на прогулке,
сохранить фотографии и прогресс. Для живого подтверждения выбрать доступный
общественный подход к месту и проверить точность GPS. Порог сервера 70 м,
точность до 30 м. Планировать открытие карты с учётом квоты Mapbox.

## Порядок показа

| Время | Действие | Ожидаемый результат и пояснение |
|---|---|---|
| 0–1 мин | Открыть стартовый экран и нажать «Начать прогулку» | «Вандроўка помогает исследовать город, открывать культурные места и сохранять воспоминания» |
| 1–2 мин | Открыть «Исследовать», карту/список и карточку места | Название, история, категории и доступные сведения о месте |
| 2–4 мин | Рядом с местом открыть камеру, сделать фото, загрузить и подтвердить | Первое открытие даёт +100 XP, повторное посещение 0 XP |
| 4–5 мин | Открыть «Посещения» и фотографию | Сохранённое посещение, дата и личное фото |
| 5–6 мин | Открыть «Профиль» | Серверные XP, уровень, достижения и коллекция |
| 6–7 мин | Вернуться к исследованию и включить фильтр посещённых мест | Личная карта открытий |

В помещении на шаге подтверждения показать заранее сохранённое посещение
и сообщить, что оно получено на прогулке. Для показа первого открытия
выбрать место, за которое тестовый аккаунт ещё не получал XP.

Первая коллекция «Исторический центр Минска» состоит из Верхнего города,
Свято-Духова собора и Троицкого предместья. Три первых открытия дают 300 XP,
уровень 3, достижение за первое открытие и коллекцию 3/3.
Достижения дают прогресс без дополнительных XP.

## Если действие прервалось

- При плохой точности GPS повторить фиксацию на открытом пространстве.
- При сбое загрузки восстановить сеть и повторить загрузку.
- При неизвестном исходе подтверждения нажать «Проверить результат».
  Сохранённая попытка использует тот же ключ идемпотентности.
- При длительном пробуждении публичного API дождаться `/health` и повторить
  действие. Зафиксировать request ID, если ошибка повторяется.

Фактический результат и ограничения записать в отчёт для этой сборки.

## Скриншоты целевой сборки

Сделать снимки экрана на физическом телефоне с тестовым аккаунтом.

| Файл | Содержание |
|---|---|
| `01-home.png` | Стартовый экран |
| `02-explore-map.png` | Карта с местами |
| `03-explore-list.png` | Список мест |
| `04-place.png` | Карточка выбранного места |
| `05-confirmed.png` | Успешное подтверждение и XP |
| `06-history.png` | История посещений |
| `07-profile.png` | XP, уровень, достижения и коллекция |

Хранить комплект рядом с передаваемым APK, указав версию сборки.
При USB-подключении команда сохраняет изображение на компьютер.

```bash
adb -s PHONE_SERIAL exec-out screencap -p > /absolute/path/01-home.png
```

Перед передачей проверить отсутствие личной почты, уведомлений и других
приватных данных. Фото мест использовать с согласия их автора.
