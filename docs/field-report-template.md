## Достижения и коллекция

Если аккаунт был новым: после 3 разных мест ожидается 300 XP, уровень 3;
«Первое открытие» получено, достижения 5/10 ещё закрыты, коллекция центра 3/3.
Если аккаунт уже посещал места — считать ожидаемое изменение от исходного XP,
а не требовать повторно +100. Скрытие истории не позволяет получить награду снова.

## Дефекты (день 10)

| ID | P0/P1/P2 | Сборка | Шаги | Ожидание | Фактический результат | Исправление | Повторная проверка |
|---|---|---|---|---|---|---|---|
| FIELD-001 | | | | | | | |

P0: потеря данных, чужие данные, двойной XP, невозможен основной цикл/запуск.
P1: частая ошибка GPS/upload/навигации, мешающая прогулке, есть обходной путь.
P2: текст/отступы/неблокирующее неудобство.
Результат исправления подтверждается повторным сценарием на новой сборке.
