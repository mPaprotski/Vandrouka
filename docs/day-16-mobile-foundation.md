создан Expo-клиент. Проверки Android описаны отдельно ниже.

- Ветка main; есть накопленные изменённые и новые файлы backend, тестов и docs.
  Они не удалялись, не добавлялись в индекс, коммит/пуш не выполнялся.
- Все 63 удалённых из Git пути data/ существуют во внешней ../data и совпадают
  побайтно с HEAD: 60 YAML, README и два файла происхождения GPX.

- Сканирование доступных tracked/untracked текстов по шаблонам Mapbox/GitHub/AWS
  credentials и private key не обнаружило совпадений. Это проверка известных
  шаблонов, не доказательство отсутствия любого возможного секрета.
- Добавлено /data/ в .gitignore для предотвращения случайного возврата каталога.
  Уже отслеживаемые удаления остаются в рабочем дереве до отдельного коммита.

## 2. Backend — окружение восстановлено

Запущен только сервис postgres. Исторические Valhalla/API-контейнеры не трогались.
Основная vandrouka: применён только migrate up (версия 11); выполнен импорт
60 внешних YAML с -check-links=false. Основная БД не сбрасывалась.
В отдельной vandrouka_verify_20261015 проверены up → reset → up и статус всех
11 миграций; эта БД используется для интеграционных тестов.

Go vet, сборка API, форматирование и go mod verify прошли. Локальный API
запущен на временном порту 28080: health, cities, categories, 60 мест Минска
и карточка town-hall вернули 200; описание и категории карточки присутствуют.
Временный API остановлен, PostgreSQL оставлена работающей для разработки.

**Ограничение пользователя соблюдено:** реальный Mapbox не вызывался.
При запуске и проверках MAPBOX_ACCESS_TOKEN пустой, MAPBOX_URL=http://127.0.0.1:1;
generate/recalculate smoke не выполнялся. Проверки провайдера в Go-тестах
используют только локальные фиктивные HTTP-серверы. Внешние ссылки при импорте
не проверялись. Реальный Mapbox E2E этим прогоном не подтверждался.

Финальный go test ./... -race -count=1 -timeout 2m прошёл с установленными
TEST_DATABASE_DSN и TEST_DATA_DIR: PostgreSQL-интеграции и проверка реальных
60 внешних YAML не пропущены. Изменения исходной бизнес-логики не потребовались.


## 3. Android и Expo

Создан `mobile/`: Expo SDK 57, React Native 0.86, TypeScript, Expo Router,
локальный стартовый экран с раскрывающимися подсказками и development client.
Карта, API-клиент, авторизация, фото, посещения и XP пока не подключены.
SDK 57 выбран под доступный Android API 36; SDK 58 требует API 37.
Node.js закреплён на 22.23.2, Java для сборки — 17. Подготовлены `.env.example`,
инструкции и профили EAS; облачный проект EAS ещё не настроен.

TypeScript и ESLint проходят; Expo Doctor: 21/21. Устранён дубликат
expo-font разных SDK. Нативные каталоги генерируются Expo и игнорируются Git,
как и node_modules, локальные env и debug keystore.

`npm audit` сообщает 28 предупреждений (10 moderate, 18 high), включая цепочки
braces, decode-uri-component, node-forge и uuid. Это остаётся открытым вопросом
зависимостей; `audit fix --force` не применялся, поскольку предлагает несовместимую
смену SDK. Успешный Expo Doctor не означает отсутствие этих уязвимостей.

Metro успешно собрал Android JavaScript bundle (1384 модуля).
Локальная Android-сборка ARM64 завершилась: BUILD SUCCESSFUL (7 минут 5 секунд).
APK: `mobile/android/app/build/outputs/apk/debug/app-debug.apk`, около 86 МБ.
`apksigner verify` прошёл; package `by.vandrouka.app`, version 0.1.0,
minSdk 24, targetSdk 36, единственная архитектура arm64-v8a.
Это debug development build: для загрузки JavaScript нужен Metro,
он не является автономным preview/release APK.
По просьбе пользователя эмулятор не запускаем. Физический телефон не подключён;
установка и запуск приложения на устройстве не проверены.
Реальные API Mapbox не вызывались.

## Изменение требования: Expo Go

По решению пользователя основной запуск переведён на Expo Go: `npm start`
использует `expo start --go`, `npm run start:usb` — localhost:8081.
Команда автоматической нативной сборки/запуска удалена из scripts.
Ранее собранный development APK для Expo Go не нужен. Эмулятор не запускаем.
Выбран Mapbox GL JS через WebView; нативный Mapbox SDK не включаем.
Согласно документации Expo, WebView входит в Expo Go SDK 57; интеграция
Mapbox/WebGL ещё не реализована и на телефоне не проверена.
Физический телефон с Expo Go пока не проверен.

После переключения scripts на Expo Go TypeScript, lint и git diff --check прошли.

Пользователь впоследствии подтвердил запуск стартового экрана в Expo Go на телефоне.
