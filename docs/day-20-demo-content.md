## Координаты и подходы

Выполнен один запрос Mapbox Walking Directions через пять существующих координат: 1363,31 м и 976,324 с ходьбы (около 16 минут), без времени осмотра. Между точками: 220,541 / 271,627 / 593,381 / 277,761 м. Это оценка маршрутизатора, а не измерение на местности. Возврат к старту не добавляется.

Отклонения от пешеходной сети: собор Девы Марии — 32,355 м, ратуша — 3,074 м, Свято-Духов — 0,023 м, предместье — 0,034 м, остров — 1,796 м. Первая точка требует проверки подхода на месте. Исходные координаты не менялись. В карточках отдельно отмечены лестницы, переходы, мост и возможная скользкость; доступность для коляски не подтверждена.

## Хранение и запуск

Данные остаются вне Git в `../data`:

- `catalog/minsk-demo.json`: порядок, истории, подходы, источники, метаданные обложек;
- `covers/*.jpg`: пять файлов, суммарно около 1 МБ;
- `catalog/covers-metadata.json`: сведения об авторах и SHA-256;
- `sources/commons-*.json`: исходные метаданные Commons;
- `sources/minsk-demo-routing-review.json`: результат проверки маршрута, без токена.

Эти файлы нужно переносить и резервировать вместе с внешним каталогом. Compose подключает его read-only в `/app/data`, `DATA_DIR=/app/data`. Миграция БД не требуется.

При отсутствии манифеста остаётся обычный каталог. Некорректный существующий манифест, файл, лицензия или SHA-256 останавливают запуск с ошибкой. `/catalog-media/{filename}` отдаёт только заранее загруженные обложки из манифеста, поддерживает GET/HEAD, ETag и кеширование; произвольные файлы DATA_DIR и будущие приватные фотографии пользователей недоступны.

API добавляет необязательный `Place.content`. В «Исследовать» по умолчанию выбраны пять мест; переключатель возвращает все 60. Карта и список используют одну выборку. В карточке доступны обложка, история, подход, ссылки и статус проверки. Если фото не загрузилось, остальная карточка работает.

Автоматические проверки: Go `-race`, `go vet`, форматирование изменённых Go-файлов, мобильные тесты, TypeScript, ESLint, Android export без эмулятора, контракт OpenAPI. Тесты контента используют временные файлы и не требуют внешней сети. Полный Go-прогон повторён с TEST_DATABASE_DSN на отдельной БД `vandrouka_verify_20261015`: интеграционные тесты прошли. Локальный Docker API пересобран: health, 60 мест, пять обогащённых карточек, GET/HEAD всех пяти JPEG и 404 неизвестного файла проверены. Основная БД не пересоздавалась.
