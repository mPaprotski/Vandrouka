# Mapbox: маршрутизация

Рабочий CLI использует Mapbox Matrix и Directions с профилем `mapbox/walking`.
Карта, Geocoding и Isochrone в текущей реализации ещё не подключены.

## Запуск

Нужны PostgreSQL с импортированным каталогом и токен Mapbox в окружении.
Файл `.env` автоматически не загружается; используйте `export` или загрузите
собственный игнорируемый Git файл окружения. Не помещайте токен в командную
строку, README или Git. В `.env.example` оставлен пустой параметр.

```bash
cd backend
# MAPBOX_ACCESS_TOKEN должен быть задан в окружении заранее.
POSTGRES_DSN='postgres://postgres:postgres@localhost:25432/vandrouka?sslmode=disable' \
go run ./cmd/planner --budget 180 --categories museums,architecture \
  --start-time 2026-10-21T10:00 --ticket-budget 15 --seed 42
```

По умолчанию выводятся до трёх вариантов с проверенным через Directions
порядком переходов. Для одного варианта добавьте `--variants=false --profile=budget`.
Для расчёта только по Matrix добавьте `--geometry=false`.
`cmd/routing-check` проверяет Matrix и Directions на небольшом наборе точек.

## Клиент

- `MAPBOX_URL`: по умолчанию `https://api.mapbox.com`; заменяется только для
  локальных HTTP-заглушек в тестах.
- `MAPBOX_ACCESS_TOKEN`: обязательный для CLI; каталог и health работают без него.
- Matrix: координаты передаются как `longitude,latitude`, запрашиваются duration
  (секунды) и distance (метры), в доменную модель расстояние переводится в км.
- До 25 уникальных координат используется один запрос. Для большего набора
  матрица собирается из направленных блоков по 12 источников и 12 целей;
  повторы координат отображаются обратно на исходные индексы.
- Для 61 уникальной точки полный расчёт требует до 36 запросов и 3721 элементов.
  Профили planner не повторяют запросы: используют ту же матрицу.
- Клиент выдерживает интервал 1,05 секунды между запросами, учитывает отмену
  контекста и не повторяет платные запросы автоматически. Лимит относится к
  одному клиенту; при нескольких процессах нужен общий контроль расхода.
- `null` или `NoRoute` в Matrix означает недостижимость, без прямолинейной подмены.
- Directions разбивает длинный путь на части максимум по 25 координат с общей
  граничной точкой. Геометрия возвращается как массив частей polyline6;
  длительности каждого перехода доступны отдельно и проверяются planner.
- Ошибки авторизации, 429 и недоступности различаются. Токен, URL запроса
  и произвольное сообщение провайдера в ошибки не включаются.
- Длительности провайдера соответствуют обычному темпу. Пользовательский темп
  применяется один раз в planner. Итоговые переходы Directions могут отличаться
  от Matrix: CLI проверяет ограничения заново и исключает недопустимые варианты.

Кеширование пока отсутствует, каждый запуск CLI получает новую матрицу.
Для многопользовательского запуска ещё нужны общий лимитер и учёт квоты.

## Проверки

Тесты без реального Mapbox проверяют сборку матриц на 2/25/26/61 точке,
направленность, единицы, null, ошибки, отмену, отсутствие токена в ошибках,
разбиение длинных маршрутов и профили. CI не требует токена и не вызывает Mapbox.

Полный набор Go-тестов с `-race` и отдельной PostgreSQL-базой прошёл.
Сквозной CLI проверен с реальным каталогом и локальной HTTP-заглушкой Mapbox;
повторные запуски воспроизводимы. Реальный Mapbox проверен с локальным токеном: матрица 10×10, все пары
достижимы; Directions от ратуши к Троицкому предместью вернул 563,278 секунды,
0,82551 км и геометрию. Полный CLI также проверен: после уточнения Directions
остался один допустимый маршрут на 158 минут и 0 BYN, другой вариант исключён
за нарушение ограничений. Valhalla удалена из активного Compose; данные и
исторические отчёты сохранены. Новая конфигурация не останавливает уже
работающий старый контейнер автоматически.

Источники контрактов: [Matrix API](https://docs.mapbox.com/api/navigation/matrix/)
и [Directions API](https://docs.mapbox.com/api/navigation/directions/).
