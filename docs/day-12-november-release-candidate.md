# 12 ноября — feature freeze и подготовка RC

Этап выполняется заранее 7 ноября 2026 года. С этого этапа новые игровые
функции откладываются до выпуска; допустимы исправления блокирующих дефектов
и повторные проверки. Release candidate пока не объявлен готовым.

## Выполнено локально

- В CI добавлен mobile job: Node 22.23.2, npm ci, тесты, typecheck и lint.
  Backend job уже проверяет race, vet, сборку, миграции up/reset/up и контракт.
  Удалённый GitHub Actions запуск не выполнялся: изменения не отправлены.
- Повторная регрессия дня 11: backend с race и отдельной тестовой PostgreSQL,
  vet, мобильные тесты/типы/lint, OpenAPI и локальный игровой E2E пройдены.
- В этапе 12 повторно пройдены 20 мобильных тестовых файлов, typecheck и lint;
  YAML workflow и Compose валидны. Полный backend Docker build успешен.
  Локальный image ID `sha256:12cda2978c92e5748e2ea6536ad8b760387fbbfbe50e3c986ad1aa9299a992a4`;
  проверочный tag `vandrouka-api:nov12-check`, работающий API им не заменялся.
- Миграции `up → reset → up` до 16 пройдены на новой уникальной БД;
  после проверки она удалена. Рабочая БД не сбрасывалась.
- Приватный snapshot `/tmp/vandrouka-nov12-backup` создан; API кратко
  останавливался и был снова запущен. SHA256 и восстановление в отдельную
  временную БД проверены: 60 places, 0 visits, 0 photos; 56 записей архива MinIO.
  Рабочая БД не восстанавливалась и не сбрасывалась.
  После завершения API `/health` вернул `{"status":"ok"}`.

Backup в /tmp — репетиция, не долговременная копия. HTTP-чтение фото из
восстановленного S3 не проверено; snapshot не содержит пользовательских фото
в метаданных. Внешние Neon/R2, расписание и независимое хранение не проверены.

После изменения кода/конфига/бинарника карточку обновить, затронутые проверки
повторить. Тестовый Docker tag сам по себе не фиксирует RC: для передачи нужны
image digest, commit и SHA256 APK. Секреты и содержимое приватных копий в карточку
не помещать. Не использовать локальную сборку с LAN API как внешний демо-релиз.
