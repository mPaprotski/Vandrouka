## Данные и контракты

60/60 YAML содержат summary, но это краткие описания, а не подтверждение готовности
полноценной истории/обложек для игрового клиента. В модели/API/данных нет полей
фотографий/обложек, visit_radius_m, base_xp, district. Для первого MVP радиус
и +100 XP могут быть серверными настройками; поля для каждого места — отдельное решение.
Есть is_active, но нет пользовательского статуса посещения.
Часы известны у 3 мест, цены — у 34; неизвестность уже сохраняется в Planner.
Проверить компактный набор 5–10 мест: координаты доступного подхода, описание,
условия посещения и права на обложки. Наличие 60 записей не означает полевую проверку.

OpenAPI содержит только 7 существующих операций: health, cities, categories,
city places, place details, generate, recalculate. Auth/users/visits/upload/
progress/achievements endpoints пока нет даже в контракте. Каталог по
/v1/cities/{slug}/places сохраняем; дублировать его новым /v1/places не обязательно.
Фотохранилище и Redis в Compose не подключены; лимиты сейчас в памяти процесса.
